PUT YOUR CV HERE
================

The "Download CV (PDF)" button on /about.html points to:

    /assets/documents/adebayo-olawunmi-cv.pdf

Save your CV into THIS folder with EXACTLY that filename
(lowercase, hyphens not spaces), then commit and push.

Notes
-----
* PDF only. A .docx exposes document metadata and edit history,
  and many phones will not open it.
* Until the file exists, the button automatically becomes a
  "Request CV by email" link instead of 404-ing. That fallback
  lives in js/app.js.
* Keep it under ~2MB for Nigerian mobile data.
* The /cv shortcut in vercel.json also points here.

Delete this file once the CV is in place.
